# Super Minecraft Galaxy (code name GalaxyCraft)

## Roadmap

`ROADMAP.md` is the user's roadmap. Keep it current without being asked:

- When the user mentions a feature or idea for the future, add it to its **Inbox** with the date.
- When a feature is merged into `master`, move it to **Done** with the date and commit, and update
  **Now** / **Next**.
- When the user decides an Inbox idea (or changes priorities), move it to its theme with a status.
- Bump "Last updated". Say in one line what changed in the roadmap.
- The public version is the Claude Doc "Super Minecraft Galaxy Roadmap"
  (https://claude.ai/code/artifact/13da9f8a-c478-4796-9cb8-b4a0b673ce00), written for players:
  no branches, commits, bugs or notes to Claude. When a feature moves to Now, Next or Done, update
  it there too, if the Claude Docs connector is available.
