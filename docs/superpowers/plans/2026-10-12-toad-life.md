# Toad life Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Toads walk and turn on the voxel ground, live in a hut with a door and a bed, and behave like villagers.

**Architecture:** A pure `ToadWander` state machine over a `Terrain` interface; a client `ToadWalker` that implements it with the planets' ground rays and cells and moves the records; `Huts` builds the door and bed and reports the bed spot; `ToadRecord` gains an optional `home`.

**Tech Stack:** Java 25, JUnit 5, the existing planet queries (`PlanetSession.surfaceAlong`, cells).

**Spec:** `docs/superpowers/specs/2026-10-12-galaxycraft-toad-life-design.md`

## Global Constraints

- No merge/push/Discord; no Dolphin unless the orchestrator gives the slot; branch `feat/toad-npcs`.
- Old `toads.json` must load unchanged (new fields optional).
- Pure classes use no Minecraft types. Walking never runs for a planet that is not active.

## Review Focus

- A Toad stuck against a player-placed wall or in a corner: it picks another heading, never jitters in place for ever.
- The ground vanishes under a Toad (the player digs): it falls with the planet's gravity, does not float.
- A Toad being talked to must not wander off mid-sentence (the box closes at 8 blocks).
- Two Toads in one hut or a Toad on a station deck: leash and no-fall at deck edges (stations: no wander; Technician stays).
- Saved position must not drift or be written every frame.

### Task 1: ToadWander (pure)

**Files:** Create `fabric/src/main/java/dev/moui/galaxycraft/toad/ToadWander.java`, test `ToadWanderTest.java`.

**Interfaces:**
- Produces: `interface Terrain { double groundAt(double x, double z); boolean blocked(double x, double z, double y); }` (planar coordinates in blocks around the home, y the ground height), `ToadWander(double homeX, double homeZ, double leash, long seed)`, `Step step(double dt, double x, double z, double y, Terrain t, boolean night, boolean playerNear, boolean talking)` returning `record Step(double dx, double dz, double heading, String anim)`.

- [ ] **Step 1: tests** (fake terrains as lambdas): (a) over 600 simulated seconds the position never exceeds leash + 0.5 from home; (b) with a wall line across x = 2 the Toad never crosses it and does not stand still forever (moves in the last 60 s); (c) a 1-block step is climbed (groundAt rises by 1), a 3-block drop is refused; (d) at night and not talking it ends at the home point with anim "Sleep"; with `playerNear` it wakes; (e) `talking` gives zero movement and "Wait"; (f) same seed, same path.
- [ ] **Step 2:** Implement: states IDLE (2-6 s), TURN (to a new heading, ~0.8 s, anim "Turn"), WALK (1.1 blocks/s up to a target within the leash, anim "Walk"); try heading, then +-60 degrees, then a new target; `stuck` counter resets the target after 3; night -> target = home, then SLEEP.
- [ ] **Step 3:** Run tests, commit `toad: ToadWander, idle wander with turns, a leash, steps and night`.
