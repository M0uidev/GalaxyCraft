# Toad Brigade Ship Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A craftable, modular Toad Brigade ship the player boards with right click, flies between planets, and leaves with Shift, drawn from SMG2's real models.

**Architecture:** A ship is a mod-managed object (like drops and stations, not a Minecraft entity): a saved record of its modules and place, drawn by `EntityClient` as rigid pieces through the existing MODEL/SKIN/ENTITIES records, boarded through the existing seat and elytra flight. Its models come from arcs the launcher copies from the player's disc and a Java BDL reader turns into quads at run time. The C++ module is untouched.

**Tech Stack:** Java 25 (Fabric mod, JUnit 5, Gradle), JavaScript (launcher, `node --test`), JSON recipes/advancements/lang.

**Spec:** `docs/superpowers/specs/2026-10-11-galaxycraft-toad-ship-design.md` (amended by Task 1: ship is mod-managed; conversion is in Java).

## Global Constraints

- Nothing from the disc is committed or shipped; arcs are copied from the player's own `.rvz` at install (`dolphin-tool extract -s`), as the soundtrack does.
- Without the arcs the ship is still drawn (tinted cubes): never an invisible vehicle.
- The C++ module (`syati/`) and Dolphin patch are not changed.
- Boarding: right click; leaving: Shift (as boats and minecarts).
- Advancements are never required to craft anything; the Ship Table has a plain recipe.
- Code ids stay `galaxycraft`; player-facing text says "Super Minecraft Galaxy" / item names as in `lang/en_us.json`.
- Run Gradle with `env JAVA_HOME="$(ls -d ~/.local/opt/jdk-25* | head -1)"` from `fabric/`.
- Commits end with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
- Work in the worktree `/home/moui/Documents/Games/GalaxyCraft-toad-ship` (branch `feat/toad-ship`). Never test while the user's `gxplay` runs (it shares `/dev/shm` and the ctl channel).

## Review Focus

- A ship with no engine or no cabin: the table refuses; a loaded save with such modules is repaired (treated as the weakest valid ship), never crashes.
- The disc has none of the five arcs, or one is corrupt/unsupported: that piece falls back to a tinted cube; the game never throws on the render thread.
- A ship parked where its planet is not in focus (or after the floating origin moves): drawn at the right place, saved in galaxy units, not lost.
- Two ships close together, or 100 ships: pieces beyond `Layout.ENT_MAX` are dropped, never overflow the frame.
- Shift while the ship is moving fast or over the void: the player is released without a fall kill (SMG2's abyss kill is already skipped while seated).

```java
package dev.moui.galaxycraft.ship;

/** A ship's modules, each a tier 0 (none) to 3. Engine and cabin are required. */
public record ShipModules(int hull, int engine, int rudder, int cabin) {
    public static final int MAX_TIER = 3;

    public boolean valid() {
        return engine >= 1 && cabin >= 1
                && hull >= 0 && rudder >= 0 && engine <= MAX_TIER && cabin <= MAX_TIER
                && hull <= MAX_TIER && rudder <= MAX_TIER;
    }

    /** The weakest valid ship that keeps what is sound (a corrupt save never crashes the game). */
    public ShipModules repaired() {
        return new ShipModules(clamp(hull, 0), clamp(engine, 1), clamp(rudder, 0), clamp(cabin, 1));
    }

    private static int clamp(int v, int min) {
        return Math.max(min, Math.min(MAX_TIER, v));
    }
}
```

```java
package dev.moui.galaxycraft.ship;

import com.google.gson.JsonArray;
import com.google.gson.JsonElement;
import com.google.gson.JsonObject;
import com.google.gson.JsonParser;
import java.io.IOException;
import java.nio.file.Files;
import java.nio.file.Path;
import java.util.ArrayList;
import java.util.List;
import java.util.Optional;

/** The ships of one galaxy, kept in a JSON file next to its planets. */
public final class ShipStore {
    private final Path file;
    private final List<ShipRecord> ships = new ArrayList<>();

    private ShipStore(Path file) {
        this.file = file;
    }

    public static ShipStore load(Path file) {
        ShipStore s = new ShipStore(file);
        try {
            if (!Files.exists(file)) return s;
            JsonArray a = JsonParser.parseString(Files.readString(file)).getAsJsonArray();
            for (JsonElement e : a) {
                JsonObject o = e.getAsJsonObject();
                JsonArray p = o.getAsJsonArray("pos");
                ShipModules m = new ShipModules(o.get("hull").getAsInt(), o.get("engine").getAsInt(),
                        o.get("rudder").getAsInt(), o.get("cabin").getAsInt()).repaired();
                s.ships.add(new ShipRecord(o.get("id").getAsString(), m,
                        new double[] {p.get(0).getAsDouble(), p.get(1).getAsDouble(), p.get(2).getAsDouble()},
                        o.get("yaw").getAsFloat()));
            }
        } catch (IOException | RuntimeException e) {
            s.ships.clear(); // a damaged file loses its ships, not the world
        }
        return s;
    }

    public List<ShipRecord> all() {
        return List.copyOf(ships);
    }

    public void put(ShipRecord r) {
        ships.removeIf(x -> x.id().equals(r.id()));
        ships.add(r);
    }

    public Optional<ShipRecord> remove(String id) {
        for (ShipRecord r : ships)
            if (r.id().equals(id)) {
                ships.remove(r);
                return Optional.of(r);
            }
        return Optional.empty();
    }

    public void save() throws IOException {
        JsonArray a = new JsonArray();
        for (ShipRecord r : ships) {
            JsonObject o = new JsonObject();
            o.addProperty("id", r.id());
            o.addProperty("hull", r.modules().hull());
            o.addProperty("engine", r.modules().engine());
            o.addProperty("rudder", r.modules().rudder());
            o.addProperty("cabin", r.modules().cabin());
            JsonArray p = new JsonArray();
            for (double v : r.pos()) p.add(v);
            o.add("pos", p);
            o.addProperty("yaw", r.yaw());
            a.add(o);
        }
        Files.createDirectories(file.toAbsolutePath().getParent());
        Files.writeString(file, a.toString());
    }
}
```

```java
import net.minecraft.core.registries.Registries;
import net.minecraft.resources.Identifier;
import net.minecraft.resources.ResourceKey;
import net.minecraft.world.item.CreativeModeTabs;
import net.minecraft.world.item.Item;
import net.minecraft.world.level.block.Block;
import net.minecraft.world.level.block.SoundType;
import net.minecraft.world.level.block.state.BlockBehaviour;

/** The Ship Table, the module items and the assembled ship. */
public final class ShipBlocks {
    public static Block TABLE;
    public static Item TABLE_ITEM, HULL, ENGINE, RUDDER, CABIN, TOAD_CORE, TOAD_SHIP;

    private ShipBlocks() {}

    private static Identifier id(String path) {
        return Identifier.fromNamespaceAndPath("galaxycraft", path);
    }

    private static Item item(String path, int stack) {
        ResourceKey<Item> k = ResourceKey.create(Registries.ITEM, id(path));
        return Registry.register(BuiltInRegistries.ITEM, k, new Item(new Item.Properties().setId(k).stacksTo(stack)));
    }

    public static void register() {
        if (TABLE != null) return;
        ResourceKey<Block> tk = ResourceKey.create(Registries.BLOCK, id("ship_table"));
        TABLE = Registry.register(BuiltInRegistries.BLOCK, tk,
                new ShipTableBlock(BlockBehaviour.Properties.of().setId(tk).strength(3, 6).sound(SoundType.METAL)));
        ResourceKey<Item> tik = ResourceKey.create(Registries.ITEM, id("ship_table"));
        TABLE_ITEM = Registry.register(BuiltInRegistries.ITEM, tik,
                new net.minecraft.world.item.BlockItem(TABLE, new Item.Properties().setId(tik).useBlockDescriptionPrefix()));
        HULL = item("ship_hull", 16);
        ENGINE = item("ship_engine", 16);
        RUDDER = item("ship_rudder", 16);
        CABIN = item("ship_cabin", 16);
        TOAD_CORE = item("toad_core", 16);
        ResourceKey<Item> sk = ResourceKey.create(Registries.ITEM, id("toad_ship"));
        TOAD_SHIP = Registry.register(BuiltInRegistries.ITEM, sk, new ToadShipItem(new Item.Properties().setId(sk).stacksTo(1)));
        CreativeModeTabEvents.modifyOutputEvent(CreativeModeTabs.FUNCTIONAL_BLOCKS).register(o -> {
            o.accept(TABLE_ITEM);
            o.accept(HULL);
            o.accept(ENGINE);
            o.accept(RUDDER);
            o.accept(CABIN);
            o.accept(TOAD_CORE);
```

```js
'use strict';
// The five SMG2 models the Toad ship is built from, copied once from the player's own disc.
const fs = require('fs');
const os = require('os');
const path = require('path');

const DISC_DIR = 'ObjectData';
const ARCS = ['MiniPlayerRocket.arc', 'MarioFaceShipJet.arc', 'MarioFaceShipRudder.arc',
  'MarioFaceShipChimney.arc', 'SpaceShipStep.arc'];

/** extract(outDir): puts the disc's ObjectData under outDir; yaz0(buffer): decompressed buffer. */
async function install({ dir, extract, yaz0 }) {
  const work = fs.mkdtempSync(path.join(os.tmpdir(), 'smg-ship-'));
  try {
    await extract(work);
    fs.mkdirSync(dir, { recursive: true });
    let copied = 0;
    const missing = [];
    for (const name of ARCS) {
      const from = path.join(work, DISC_DIR, name);
      if (!fs.existsSync(from)) { missing.push(name); continue; }
      let data = fs.readFileSync(from);
      if (data.slice(0, 4).toString() === 'Yaz0') data = yaz0(data);
      fs.writeFileSync(path.join(dir, name), data);
      copied++;
    }
    return { copied, missing };
  } finally {
    fs.rmSync(work, { recursive: true, force: true });
  }
}

module.exports = { ARCS, DISC_DIR, install };
```

`Rarc.read`: header `"RARC"`, u32 size, u32 headerSize(0x20), u32 dataOffset (relative to 0x20), …; info at 0x20: u32 nodes, u32 nodeOffset, u32 entries, u32 entryOffset, u32 stringsSize, u32 stringOffset (all relative to 0x20). `BdlReader.read`: magic at 0 must be `J3D2bdl3` or `J3D2bmd3` (8 bytes) else `IllegalArgumentException`; chunk count u32 at 0x0C; chunks start at 0x20, each `tag(4) size(u32)`.
- `VTX1` at `v`: u32 `fmtOff` at `v+8`; 13 u32 array offsets at `v+12`; format entries at `v+fmtOff`, 16 bytes each `attr u32, cnt u32, ctype u32, frac u8` until `attr==0xFF`. Array of attr 9 (position) starts at `offs[0]`, attr 13 (TEX0) at `offs[5]`; length = `(nextLargerOffset or sectionSize) - start`; components: position `cnt==0 ? 2 : 3`, TEX0 `cnt==0 ? 1 : 2`; ctype 0 u8, 1 s8, 2 u16, 3 s16, 4 f32; integer types divide by `1 << frac`.
- `SHP1` at `s`: u16 count at `s+8`; offsets at `s+12`: init, remap, name, desc, mtxtab, dl, mtxdata, pkt (8 × u32). Shape init at `s+init+i*0x28`: `u8 type, u8 pad, u16 mtxGroupCount, u16 descIndex, u16 firstMtxData, u16 firstPkt`. Descriptor at `s+desc+descIndex`: pairs `u32 attr, u32 type` until `attr==0xFF`; type 2 = u8 index, 3 = u16 index, type 1 = direct u8 only for attr 0 (matrix index), anything else → `IllegalArgumentException`. Packet record at `s+pkt+(firstPkt+p)*8`: `u32 size, u32 offset`; display list at `s+dl+offset`; ops `0x90` triangles, `0x98` strip, `0xA0` fan, `0x00` ends, others → `IllegalArgumentException`. Per vertex read attrs in descriptor order; keep index of attr 9 and 13.
- `TEX1` at `t`: u16 count at `t+8`, u32 headerOffset at `t+12`; each header 0x20 bytes at `t+headerOffset+i*0x20`: u8 format, u8 alphaEnabled, u16 width, u16 height, … u32 imageOffset at +0x1C (relative to that header). /** Where the cabin's cushions are, in pixels from the cabin's middle (nose +z): driver first, then pairs behind. */

```java
        for (int i = 0; i < n; i++) out.add(SLOTS[i].clone());

}
```
