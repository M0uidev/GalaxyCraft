# Launcher Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Opening GalaxyCraft opens Minecraft's menu over Dolphin's window. SMG2 boots by itself
into GalaxyCraftSpace. Each Minecraft world is a galaxy whose planets and player spot persist, and
settings persist.

**Architecture:** The module gets a boot autopilot and holds Mario in GalaxyCraftSpace until the
mod places him. Dolphin gets a "menu" mode driven by a new header word from the mod
(`mod_screen`). The mod becomes a normal client: a per-world planet store, a space bootstrap (a
default planet and a teleport to the saved spot), a branded title screen and new-world defaults.
`gxplay.sh` launches both with their own folders.

**Tech Stack:** Syati/Kamek C++ (CodeWarrior), Dolphin C++ (patch regenerated with
`git -C dolphin/src diff HEAD`), Fabric 26.3 Java 25, Python 3 tools.

**Spec:** `docs/superpowers/specs/2026-10-05-galaxycraft-launcher-design.md`

## Global Constraints

- Galaxy name: `GalaxyCraftSpace`; scenario 1; built by `tools/space_galaxy.py` from `RedBlueExGalaxy`.
- Env `GALAXYCRAFT_BOOT=space` turns the autopilot on (host flag `GXC_MBX_BOOT_SPACE`); without
  it the game behaves exactly as today (dev harness, old routes).
- Game folder: `$XDG_DATA_HOME/galaxycraft/minecraft`; Dolphin folder: `$XDG_DATA_HOME/galaxycraft/dolphin`.
- A world's galaxy: `saves/<world>/galaxycraft/planets/` + `saves/<world>/galaxycraft/player.json`.
- Blueprints: shared, `<game dir>/galaxycraft/blueprints` (game tests: unchanged, beside `planetDir`).
- `-Dgalaxycraft.planetDir` still wins everywhere (game tests).
- Never run harness tests while the user plays (`/dev/shm/galaxycraft_v1` is shared).
- Dolphin patch: edit `dolphin/src`, then `git -C dolphin/src add -N <new files>; git -C dolphin/src diff HEAD > dolphin/patches/0001-galaxycraft.patch`.

## Review Focus

- Relaunch with an existing world: planets, inventory and spot come back. Covered by LauncherProbe (re-enter).
- Leaving a world and entering another one: no planet of the first shows up in the second.
  Covered by the PlanetClient world switch unit test and LauncherProbe.
- No SMG2 save at all (fresh Dolphin folder): the autopilot must create a file. Covered by `gxvoxel.sh boot --empty-nand`.
- Minecraft at its title for minutes before entering a world: Mario must not die or restart
  the stage. Covered by `gxvoxel.sh boot` (Mario still at origin after 20 s).
- Esc on the title screen or in menus must not reach SMG2 as +. Menu mode sends nothing to
  the Wii Remote; `MarioInput` unit check in `dolphin/galaxycraft/tests`.

### Task 2: Module boot autopilot and holding Mario

**Files:** `syati/src/Boot.cpp` (+ `Boot.h`), `syati/src/GalaxyCraft.cpp` (call hooks, dbg),
`protocol/galaxycraft_protocol.h` (`GXC_MBX_BOOT_SPACE 1024u`, `GXC_MBX_HOLD 2048u`).

**Interfaces produced:** `void BootSelectorControl(void*)` (vtable), `bool BootHoldMario()`, and
`void BootMarioFrame(LiveActor* mario)`, called from `MarioMovement` before the original.
`dbg.boot[4]` = selector, nerve, frames in that nerve, step bits.

- [ ] Autopilot runs only with `host_flags & GXC_MBX_BOOT_SPACE`. Title: kill the
  TitleSequenceProduct after 30 frames. Choose (15784): `onSelect` on the first non-new item;
  if all are new, `onSelect(item 0)`, then drive the create path (map the nerves 15744..15708 in
  the harness with an empty NAND; confirm with `setNerve` on the nerve that the "OK" button
  sets). File chosen (15764), step > 20: `setNerve(15760)`.
- [ ] `requestChangeStageAfterFileSelect` → GalaxyCraftSpace only with the flag. Without it, the
  game's own code runs: the kmCall becomes a function that calls the original branch target
  when the flag is off. The patch sits at 0x804D62FC: if off, run the original `addi r3,r31,92;
  bl isOnGameEventFlag` path, done by branching back to 0x804D62FC's original instruction stream
  through a trampoline.
- [ ] Hold: in stage GalaxyCraftSpace, while `host_flags & GXC_MBX_HOLD` or no PLANET_TP since
  the hold started, Mario's position is set to the origin and his velocity zeroed each frame,
  and the abyss kill patch is on.
- [ ] Build; harness check (Task 3).

### Task 3: Harness boot check

### Task 4: Dolphin menu mode

**Files:** `dolphin/src/Source/Core/Core/GalaxyCraft.cpp`, `dolphin/galaxycraft/HostBridge.{h,cpp}`,
`protocol/galaxycraft_protocol.h` (header word `mod_screen`, `GXC_SCREEN_MENU 1`, `GXC_SCREEN_WORLD 2`,
version bump), `dolphin/src/Source/Core/VideoCommon/OnScreenUI.cpp`.

- [ ] HostBridge: `SetBootSpace(bool)`. When it is on, every tick that has a mailbox writes
  `host_flags` with `BOOT_SPACE`, plus `HOLD` while `!InWorld()`. `bool InMenu() const` =
  boot space && (mod not alive || mod_screen != WORLD). In menu: no follow, Wii Remote override
  on with a neutral pad. Unit tests in `dolphin/galaxycraft/tests` (the existing test style).
- [ ] GalaxyCraft.cpp: `GALAXYCRAFT_BOOT=space` → `SetBootSpace(true)`. Input: in menu, keys,
  buttons, wheel, text and pointer go to Minecraft (pointer always inside), the mouse is not
  captured, Escape goes to Minecraft, and nothing goes to Mario. Audio: `Config::SetCurrent(
  MAIN_AUDIO_VOLUME, 0)` while in menu, restored after (the saved value is kept).
- [ ] Overlay: `WithOverlay` also composites in menu mode (no Minecraft-mode check). OnScreenUI:
  when in menu and no frame yet, fill the window black with "GalaxyCraft" centered.
- [ ] Build (`dolphin/build.sh`), regenerate the patch, run `dolphin/galaxycraft/test.sh`, commit.

### Task 6: A world's galaxy (per-world store, player spot, space bootstrap, leaving)

**Files:** create `fabric/src/main/java/dev/moui/galaxycraft/voxel/GalaxySave.java` (folder layout +
`player.json`: planet index, direction from center, yaw, pitch); modify `PlanetClient.java`,
`GalaxyCraftClient.java`; test `fabric/src/test/.../voxel/GalaxySaveTest.java`.

**Interfaces:** `GalaxySave.of(Path worldDir)`; `Path planets()`; `Optional<Spot> spot()`;
`void writeSpot(Spot)`; `record Spot(int planet, double dx, double dy, double dz, float yaw, float pitch)`.
`PlanetClient.useWorld(GalaxySave or null)`; `PlanetClient.spaceTick(BridgeClient, WorldState)`.

- [ ] GalaxySaveTest: spot round trip, a missing file → empty, a corrupt file → empty.
- [ ] PlanetClient: `store`/`blueprints` no longer static final; `useWorld` saves and unloads the
  current planets (sending GONE), switches store and forces `enterStage` again. With `planetDir`
  set, the property store is kept. JOIN: `useWorld(GalaxySave.of(server.getWorldPath(ROOT)))`.
  DISCONNECT: save the spot, `useWorld(null)`.
- [ ] Space bootstrap, from `beforeTick`'s no-frame branch when the stage is GalaxyCraftSpace:
  load the planets. If there are none, generate `PlanetBlueprint.standard("Home", DEFAULT_RADIUS)
  .withMode(GENERATED)` and spawn it at the origin. Then teleport toward the saved spot's
  direction (else up, +Y) once the planet is active. Planet messages are sent with no frame too.
- [ ] Spot saved every 600 ticks and on disconnect (the planet in focus, direction from its center, look).
- [ ] Starter kit and game rules on a world's first join (no `galaxycraft/` folder yet).
- [ ] `./gradlew test`, commit.
